# Travel Planning App — Web Application

Next.js App Router application backed by Supabase.

## Environment
Copy `.env.example` to `.env.local` and provide the project URL and publishable key. Never commit secret/service-role keys.

## Foundation
- Next.js 16 App Router
- React 19
- Supabase SSR authentication
- Supabase/Postgres with RLS
- Node.js 22+

The Texas trip is the first end-to-end product validation scenario.
